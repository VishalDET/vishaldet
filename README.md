## 🌟 Featured Projects

### 🌌 [Niyantra Landing](https://github.com/VishalDET/niyantra-landing) (Interactive 3D Display)
An immersive, high-converting product page for an Enterprise IT hardware management platform.
*   **Tech Stack**: React, React Three Fiber (`three.js`), React Drei, GSAP, Framer Motion, Tailwind CSS.
*   **Key Highlights**: Renders high-fidelity interactive 3D hardware components in-browser, triggered via fluid, scroll-driven GSAP animations.

### 💼 [Volshebny CRM](https://github.com/VishalDET/volshebnyCRM) (Enterprise Logistics Software)
A bespoke CRM solution tailored for a travel and hospitality firm, replacing legacy spreadsheet workflows.
*   **Tech Stack**: React, Node.js API, Express, NoSQL.
*   **Key Highlights**: Handles customer profiling, partner integrations, dynamic ledger entries, bookings, and automated invoicing.

### 🤖 [Fake News Detector](https://github.com/imvishalprajapati/fake-news-detector) (AI-Powered Analysis)
A full-stack application that leverages artificial intelligence to analyze and score the credibility of web articles in real time.
*   **Tech Stack**: React, Google Gemini AI API, Firebase (Auth & Realtime Database).
*   **Key Highlights**: Caches and processes article verification requests dynamically, displaying granular AI assessment logs.

### 🚲 [Schaffler Bike Showcases](https://github.com/imvishalprajapati/schafflerBikeV2) (Scroll-Driven UX)
A series of high-performance product landing pages designed for EV bikes to showcase mechanical builds and visual details.
*   **Tech Stack**: React, GSAP ScrollTrigger, CSS custom properties.
*   **Key Highlights**: High frame rate, smooth micro-animations simulating detailed bike component walkthroughs as the user scrolls.
